# MMD Studio

> 安卓端的 MMD（MikuMikuDance）模型查看与动画编辑工具，实时 3D 渲染，原生界面。

[English](README.en.md) · **简体中文**

---

## 这是什么

MMD Studio 让你在手机上打开、调整和录制 MMD 模型与动作 —— 不需要电脑，
也不需要先把工程文件转成别的格式。直接读取 PMX / PMD 模型与 VMD 动作，
实时渲染，随手调参，拍完即存。

渲染层基于 Babylon.js，界面是原生绘制的（不是套壳网页），
所以拖动滑杆调材质时不会有网页那种迟滞感。

## 主要功能

**渲染**

- 实时 3D 全屏渲染，物理演算与 IK 解算
- 材质管线：次表面散射近似、卡通描边、边缘光、自发光、法线强度、材质换色
- 调色工具：AgX 色调映射、ASC CDL、三段色彩分级、LUT、白平衡、分离色调
- 画面特效：泛光、环境光遮蔽、景深、运动模糊、胶片颗粒、暗角、色差、锐化
- 场景控制：地面材质、天空盒与环境贴图、多光源、雾效、氛围粒子

**编辑**

- 模型：导入与移除、多模型同台、面部表情、变换手柄、位置与缩放微调
- 动作：VMD 播放、倍速、区间循环、单帧步进、动作混合、镜像、倒放、淡入淡出
- 镜头：视角预设、相机路径录制与回放、视场角调节、注视跟随
- 场景：地面与天空、灯光与阴影、背景棚、泼溅点云舞台

**输出**

- 截图（自拍定时、连拍、水印）
- 录屏
- 预设保存与导入导出
- GLB 导出

**其它**

- 中英双语界面，可跟随系统或手动切换
- 深浅色主题
- 崩溃日志写入外部存储，便于反馈问题

## 下载

到 **[Releases](../../releases)** 页下载最新安装包。

| 项目 | 要求 |
|---|---|
| 系统 | Android 7.0（API 24）及以上 |
| 存储 | 首次启动需授予「所有文件访问」权限，用于扫描设备里的模型与音频文件 |
| 网络 | 仅在检查更新时使用 |

## 模型文件怎么放

按下面这个目录结构放，App 会自动扫描：

```
/storage/emulated/0/MMDStudio/
├── Models/   # PMX / PMD（贴图放同一目录，会按相对路径自动加载）
├── Motions/  # VMD 动作与镜头数据
└── Audios/   # MP3 / WAV / OGG / FLAC / M4A
```

## 应用内更新

启动后会自动检查一次（同一台设备 6 小时内不重复），
也可以随时在「**我的 → 版本更新 → 检查更新**」手动检查。

发现新版本时会直接在应用内下载并引导安装，不需要跳转浏览器。
安装需要一次性授权「安装未知应用」，这是 Android 8.0 起的系统限制。

## 反馈

遇到问题请开 [Issue](../../issues)，并附上：

- 设备型号与系统版本
- 问题现象与复现步骤
- 崩溃日志：`Download/MMDStudio/crash/` 目录下的文件，
  或在应用内「我的 → 崩溃日志」里查看

> 如果打开就闪退、连崩溃文件都没有，多半是设备的 WebGL / GPU 驱动跑不动
> 渲染进程时的原生崩溃。这种情况下请把设备型号发出来，
> 同时可以试试把系统 WebView 更新到最新版本。
